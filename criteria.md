
# Acceptance Criteria — FitFindr

## 1. A matching query completes all three tools

Given a query that matches at least one listing, the agent completes all three tool calls and returns a fit card in at least 4 of 5 tries.

**Why this target:**

The search tool uses keyword matching rather than semantic search, so some query descriptions may not retrieve the intended listings. The outfit suggestion and fit-card tools also rely on language model generation, which can occasionally fail. A target of 4 out of 5 allows one unsuccessful attempt while still requiring reliable completion.

---

## 2. An impossible query stops before the second tool

Given a query that matches no listings, the agent stops before calling `suggest_outfit` and returns a message naming what to change in 5 of 5 tries.

**Why this target:**

The empty-search branch is controlled by the planning loop rather than the language model. When `search_listings` returns an empty list, the agent should always stop instead of attempting to generate an outfit. Since this is deterministic behavior, all five runs should pass.

---

## 3. The selected item remains consistent across tools

In 5 of 5 successful runs, the listing ID stored in `session["selected_item"]` must match the listing ID of the item passed to `suggest_outfit`.

**Why this target:**

The agent uses session state to pass information between tools. If the selected item changes unexpectedly, the outfit suggestion could be generated for a different product than the one returned by the search. Since the item is passed programmatically rather than generated by the language model, a 5 out of 5 target is reasonable.

---

## 4. The fit card includes accurate listing information

In at least 4 of 5 successful runs, the generated fit card must include the selected item's correct price and resale platform.

**Why this target:**

The fit card is intended to help users share and understand their thrift-fashion finds. Price and resale platform are important details because users need to know where an item was found and how much it costs. Since the caption is generated by a language model, an occasional omission is possible. A target of 4 out of 5 balances reliability with the variability of generated text.

---

## 5. The agent handles an empty wardrobe

Given a matching query and an empty wardrobe, the agent generates at least two outfit suggestions without claiming that the user already owns the suggested clothing in at least 4 of 5 tries.

**Why this target:**

Some users may be using FitFindr for the first time and may not have added clothing to their wardrobe. The agent should still provide useful outfit recommendations without inventing wardrobe items. Since outfit descriptions are model-generated, a target of 4 out of 5 allows for occasional wording mistakes while still expecting consistent usefulness.
